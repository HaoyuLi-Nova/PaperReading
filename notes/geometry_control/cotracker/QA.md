# CoTracker 自测问答

1. **CoTracker 与逐点 tracker 的核心区别？**
   它联合更新多条轨迹，利用点间运动相关性，而非每个点各自独立预测。
2. **virtual tracks 为什么有用？**
   它用较少代理 token 汇总大量点的信息，降低跨点注意力的内存和计算成本。
3. **它如何处理长序列？**
   在短时间窗口内因果更新，并把前一窗口的状态传给下一窗口。
4. **为什么 tracker 指标不能代表 Wan-Move 的生成控制表现？**
   追踪误差只是输入误差；生成器还可能忽略轨迹、破坏外观，或把错误轨迹放大。
5. **什么样的 CoTracker 错误值得单独分析？**
   遮挡后漂移、出视野重现错配、阴影/反射随物体一起移动，以及多个对象交互时的点身份交换。
