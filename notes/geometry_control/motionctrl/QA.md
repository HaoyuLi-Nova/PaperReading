# MotionCtrl 自测问答

1. **MotionCtrl 要解耦的两类运动是什么？**
   相机运动和物体运动。前者描述视点变化，后者描述主体相对场景的运动。
2. **为什么仅仅输入一条轨迹未必能区分二者？**
   画面中的点位移可能来自物体移动、相机移动或两者叠加；若训练标注没有拆分来源，模型无法稳定学习独立控制。
3. **它与 Wan-Move 的主要表示差异是什么？**
   MotionCtrl 显式分出相机 pose 与对象运动条件；Wan-Move 用统一点轨迹并编辑 I2V 首帧条件 latent。
4. **评估运动解耦应增加什么实验？**
   固定相机只动对象、固定对象只动相机、二者组合三种受控测试，并分别计算相机和对象运动误差及串扰。
5. **这篇的核心局限是什么？**
   真实视频中的相机与对象运动标签难以干净分离，数据噪声限制了模型可学到的解耦能力。
