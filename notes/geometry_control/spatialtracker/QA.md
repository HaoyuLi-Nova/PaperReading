# SpatialTracker 自测问答

1. **为什么 3D tracking 可缓解部分 2D 跟踪难点？**
   投影会造成遮挡和轨迹不连续；在 3D 中可使用更直接的几何关系解释运动。
2. **方法如何得到 3D 轨迹？**
   单目深度提升像素、triplane 编码场景，再由 Transformer 迭代更新轨迹。
3. **ARAP 与 rigidity embedding 的作用？**
   前者约束局部形状尽量刚性，后者将像素聚成具有相似运动的部件。
4. **用于 Wan-Move 时新增什么风险？**
   深度尺度/排序错误会变成 3D 轨迹误差，且需要把 3D 轨迹再投影回图像和 latent 坐标。
5. **什么时候应优先试它而不是 CoTracker？**
   出平面转动、相机运动或 3D 一致性是主要瓶颈时；普通 2D 控制不必默认引入这层复杂度。
