# LeviTor 自测问答

1. **LeviTor 解决普通 2D 拖拽的什么歧义？**
   轨迹点只给图像平面位置，无法区分平面移动与出平面深度运动。
2. **用户额外提供什么条件？**
   轨迹点的相对深度信息；系统还利用对象实例/分割信息组织控制点。
3. **为什么它不是完整 3D 轨迹控制？**
   相对深度不提供完整尺度、相机坐标系和绝对 3D 位置，且深度关系可能含糊。
4. **它和 Wan-Move 的接口差别是什么？**
   LeviTor 强调带深度的点拖拽和实例条件；Wan-Move 强调 2D 点轨迹到 latent 的映射与首帧特征复制。
5. **做公平消融应拆开什么？**
   分开测试深度、实例分割、聚类控制点和扩散控制模块各自的贡献。
