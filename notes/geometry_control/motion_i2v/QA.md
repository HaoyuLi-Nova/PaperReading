# Motion-I2V 自测问答

1. **为什么把 I2V 拆为两阶段？**
   先显式估计合理运动，再根据运动传播参考图内容，减轻模型直接学习复杂时空映射的负担。
2. **第一阶段预测什么？**
   参考图像素到未来帧的运动轨迹/运动场。
3. **第二阶段如何使用运动？**
   通过 motion-augmented temporal attention 对 warp 后特征进行传播和融合。
4. **它与 Wan-Move 的共通点是什么？**
   都沿运动把首帧内容信息传到后续时空位置，试图同时保持运动和外观。
5. **最大结构性风险是什么？**
   第一阶段估计的轨迹错误会限制第二阶段生成；需报告真实轨迹条件与自动预测条件的区别。
