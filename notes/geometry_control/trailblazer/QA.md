# TrailBlazer 自测问答

1. **TrailBlazer 的用户控制输入是什么？**
   主体在关键帧上的 bounding box 及相关文本提示。
2. **核心推理操作是什么？**
   利用主体 cross-attention 定位，并编辑空间/时间注意力以引导框内主体运动。
3. **为什么边界框控制较容易使用？**
   用户只需标主体区域和关键时刻，不用提供稠密像素标注或点轨迹。
4. **它无法直接保证什么？**
   主体内部点如何运动、精细形变、物理交互和相机/物体运动的严格分离。
5. **与 Wan-Move 比较时应如何对齐？**
   把 Wan-Move 点轨迹聚合成框或从相同框生成点轨迹，比较共同可表达运动范围并注明接口差异。
