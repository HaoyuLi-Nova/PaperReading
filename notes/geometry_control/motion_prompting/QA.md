# Motion Prompting 自测问答

1. **文本 prompt 在运动描述上缺什么？**
   精确路径、速度变化、动作时间点和多个部位的同步关系。
2. **论文里的 motion prompt 是什么？**
   一组可时空稀疏或稠密的点轨迹，可控制对象局部运动或全局场景/相机运动。
3. **轨迹怎样进入生成器？**
   用随机 embedding 编码并通过训练好的 ControlNet 注入视频扩散模型。
4. **Wan-Move 对该方法的主要改进主张是什么？**
   不用孤立的像素级随机轨迹 embedding，而把轨迹起点对应的首帧 latent 特征传播到后续位置，以保留邻域外观上下文；同时不加运动编码器。
5. **它与 CoTracker 的关系是什么？**
   Motion Prompting 是生成控制方法；CoTracker 是点追踪器，能为视频构造轨迹数据，两者分属生成和跟踪环节。
