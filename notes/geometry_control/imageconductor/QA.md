# Image Conductor 自测问答

1. **为什么从真实视频抽轨迹会产生歧义？**
   轨迹同时包含相机运动和对象相对运动，且自动跟踪/分割会引入误差。
2. **Image Conductor 怎样区分两类控制？**
   用不同 LoRA 权重表示相机和对象运动，并用正交约束鼓励条件分开。
3. **CoTracker 在整套方案中负责什么？**
   从训练视频抽取轨迹标注；它不是生成器里的运动控制网络。
4. **camera-free guidance 的目的是什么？**
   推理时强化对象运动并去掉不希望的相机运动。
5. **与 Wan-Move 的公平比较要控制什么？**
   相同输入轨迹、相同底模/数据和相同镜头静止设定，并测量相机—物体串扰。
